# java-calculator-precourse

---

## USE CASE

1. 사용자가 문자열을 입력한다.
2. 문자열 내 양의 정수들의 합을 얻는다.

---

### 내부 로직

1. 입력 문자열(inputString)을 구분자(기본, 커스텀)를 기준으로 분할(separateInput)
2. 분할 문자열(separateInput)에서 양수만을 추출(extractNumber)
3. 정수(extractNumber)들의 합(sum)을 계산 후 반환

---

### 내부 로직 구현 방법
[객체]
1. Separator(분할 기능) \
   **[참고]** 기본 구분자(Basic Delimiter): ',', ':' \
   **[참고]** 커스텀 구분자(Custom Delimiter): 입력값(inputString) 초반의 "//" ~ "\n" 사이의 문자 \
   1-1. 기본 구분자, 커스텀 구분자 정의
    - 기본 구분자, 커스텀 구분자가 있는지 확인하기 위해 정규표현식을 이용
    - 기본 구분자: (",|:"), 커스텀 구분자: ("//(.)\n(.*))
    - **Java.util.regex Pattern, Matcher**를 사용해서 구분자를 찾기

   1-2. 구분자를 기준으로 입력 문자열 분할
    - 커스텀 구분자가 있으면 커스텀 구분자 정의 및 커스텀 구분자, 기본 구분자로 분할
    - 커스텀 구분자가 없으면 기본 구분자로 분할

   1-3. 분할된 문자열 반환


2. Calculator(추출 및 계산) \
   **[추출]** \
   2-1. 분할 문자열을 탐색하며 양수 찾기 \
   2-2. 찾은 양수들을 반환 \
   **[계산]** \
   2-3. 양수를 더하기 \
   2-4. 계산이 끝난 합을 반환

---

### 내부로직 예외처리

1. 초기 
   1-1. 입력문자열이 null일 시
    - 0을 반환


2. 분할(Separator) 
   2-1. 구분자(기본, 커스텀)가 없을 시(No Delimiter)
    - **[추출]** 진행

   2-2. 기본 구분자, 커스텀 구분자 동시 존재
    - 모든 구분자를 기준으로 분할 진행


3. 추출(Calculator) 

   3-1. 양수가 아닐 시(음수)
    - IllegalArgumentException 발생 후, 종료
    - (음수는 입력할 수 없습니다.)

   3-2. 숫자가 없을 시(문자, 특수문자 등)
    - IllegalArgumentException 발생 후, 종료
    - (숫자가 아닌 문자는 입력할 수 없습니다.)

   3-3. 문자와 숫자가 섞여있을 시
    - IllegalArgumentException 발생 후, 종료
    - (숫자가 아닌 문자는 입력할 수 없습니다.)

   3-4. 커스텀 구분자가 여러개
    - 문제에서의 커스텀 구분자는 //~\n내의 문자라고 명시하므로 여러개가 들어간 구분자는 정의하지 않음
        - (커스텀 구분자는 여러 개를 설정할 수 없습니다.)


4. 합 계산(Calculator) 
   4-1. int 자료형보다 큰 값이 들어올 시, 오버플로우 발생
    - 문제에서 자료형에 관한 설명이 없으므로 해당 예외는 무시
